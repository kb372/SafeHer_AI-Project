# 🛡️ SafeHer AI — Smart Women’s Safety Companion

**SafeHer AI** is a student-developed safety awareness project designed to promote women's and children's safety through technology. It combines a simple web interface with image-based lighting analysis and location-access functionality.

## 🌟 Project Overview

The purpose of SafeHer AI is to demonstrate how web technologies and basic image processing can support safety awareness and encourage users to consider their surroundings.

## ✨ Features

- 📍 **Location Access:** Requests the user's permission to access their current location through the browser.
- 🖼️ **Image Analysis:** Examines an uploaded photograph to estimate its average brightness and the proportion of very dark pixels.
- 💡 **Lighting Observations:** Provides observations and practical suggestions based on image brightness.
- 🔐 **Privacy Awareness:** Uses browser permission controls for location access.
- 📱 **Web-Based Interface:** Designed to be accessible through a modern web browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- NumPy
- OpenCV

## ⚙️ How It Works

1. Open the SafeHer AI website.
2. Grant location permission if you want to use the location feature.
3. Upload a photograph of the location you want to examine.
4. Click **Analyze Image**.
5. Review the image observations and practical suggestions.

## 🚀 Run the Project Locally

### Prerequisites

Install Python and Visual Studio Code.

### Installation

Clone or download this repository, then open its folder in a terminal.

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Start the Flask application:

```bash
python app.py
```

Open the local address shown in the terminal, commonly:

`http://127.0.
